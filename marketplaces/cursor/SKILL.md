# Trembita Skill

Use this skill for robust TypeScript REST integrations with trembita.

## Use cases

- Third-party API clients with typed success/failure flows
- Resilience patterns: retries, timeouts, circuit breaker
- Status-aware calls via `client.client()`
- Testable API integration via injected `fetchImpl`
