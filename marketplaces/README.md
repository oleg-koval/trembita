# Marketplace Publishing Bundle

This directory contains submission-ready artifacts for multiple skill
marketplaces.

## Included Targets

- `cursor/` - Cursor marketplace skill packaging metadata
- `superpowers/` - Superpowers-style skill metadata
- `claude/` - Claude ecosystem skill package metadata
- `codex/` - Codex-oriented adapter metadata

## Source of Truth

- Main skill content: `../../SKILL.md`

## Publish Notes

Exact upload APIs differ by marketplace and often require dashboard submission
and account-level approval. Use `PUBLISH_CHECKLIST.md` in this directory for the
final submission flow.
